# Color27 — Color Time Machine! (CBN-first)

Fork of **HUB-ColorTime26** with a younger / store-lane desk.

## Product

- ~75% color-by-number · ~25% limited draw tools
- Stretched Drydock layout (16:9 + `stretchDesk`, same as MOAS)
- Backpack title: `Backpack:` + live bundle name (CBN and free packs may mix)
- Ships with an **empty Backpack** until clipart lands

## Desk deltas vs CT26

| Area | CT27 |
|------|------|
| Left faders | Blend/Splatter · Smudge · Zoom dial (Smoothing/Simplify removed; clean lines baked in) |
| Right faders | Opacity · Line Width · Ro' Tater dial |
| Forgiveness | Smudgies / Sharkies / OSBARD!! dock on stage (not popcorn) |
| Popcorn | Pencil · Crayon · Pastel · Marker · Star · Bucket · Eraser |
| Color tray | One Pastel tray (house + pink/gray, hue-ordered) for all draw tools |
| CBN | Page meta `cbn: true` → house tray with numbered wells |
| Overclock | No 300 PPI print-ready |
| Star FX | Rainbow toggle + MOAS-style FX set (incl. Washy) |
| HUB / q100 rail | Unchanged |

## CBN page meta

In `assets/backpack/bundle-NN/pages.json`:

```json
{
  "cbn": true,
  "pages": [
    { "file": "1 - Fox.webp", "cbn": true, "trayId": "cbn:house" },
    "2 - Free doodle.webp"
  ]
}
```

Bundle-level `"cbn": true` marks every page unless a page overrides.
